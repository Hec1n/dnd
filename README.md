# Кодекс — правила нашего мира

Редакция 0.10. Справочник мастера состоит из 14 отдельных страниц. Работает без интернета, сервера и установки зависимостей.

## Открыть

Откройте `index.html`. Для прямого перехода к персонажам — `characters.html`. Старые ссылки вида `index.html#characters` перенаправляются на соответствующую страницу.

## Разделы

- `index.html` — оглавление.
- `story.html` — сюжет, сводка текущего положения и учебный этап в деревне на 1–2 сессии.
- `npcs.html` — сводка по учреждениям и НПС, роли, цели и известные им сведения.
- `combat.html` — бой и выживание.
- `stats.html` — характеристики, перестат, ХП и удача.
- `skills.html` — закреплённые навыки и 62 предложенных навыка.
- `growth.html` — развитие и обучение.
- `equipment.html` — оружие, материалы, броня и инвентарь.
- `magic.html` — Эйра, шесть ветвей, склонности, приёмы, личные искусства, предметы и прахи.
- `faith.html` — пантеон и правила Бешабы.
- `races.html` — 68 рас и классы.
- `characters.html` — записи мастера о двух персонажах.
- `market.html` — цены и 60 позиций меню.
- `roadmap.html` — будущие дополнения, включая артефакты с дополнительными атаками.

## Редактировать

Исходный текст находится в `content/*.html`. Списки рас, оружия и богов — в `data/catalogs.json`. Общий шаблон, таблицы, навыки, меню и персонажи — в `scripts/build.mjs`. Оформление — `styles.css` и `pages.css`.

После изменения исходников выполните:

```powershell
node scripts/build.mjs
node scripts/check.mjs
```

Сборка создаёт готовые HTML-файлы. Устанавливать пакеты не нужно. Изменения сгенерированных страниц напрямую будут перезаписаны следующей сборкой.

Проверка контролирует структуру HTML, локальные ссылки, старые адреса разделов, число записей каталогов и сохранность характеристик персонажей. Визуальная проверка в браузере в этой среде не выполнялась.

## Записи мастера

Страница персонажей содержит магические сведения и владение нэн. Это мастерский справочник, а не готовые карточки для игроков. Отдельные карточки будут подготовлены позже.

Папка `.gm-notes` содержит прежние личные записи и исключена из Git. Её не нужно загружать вручную. Исключение из Git не защищает файлы от раздачи веб-сервером.

## GitHub Pages

Для публикации загрузите все 14 HTML-файлов из корня, `styles.css`, `pages.css`, `legacy-links.js` и `.nojekyll` в корень репозитория. Все ссылки относительные, поэтому сайт подходит для подпапки GitHub Pages. Исходники в `content`, `data` и `scripts` для просмотра не требуются.

В настройках репозитория выберите Pages → Deploy from a branch → нужная ветка → /(root). Перед публикацией учитывайте, что мастерская страница персонажей раскрывает их магические сведения.

## Последние решения

Удача от −2 до 1 без бонуса, 2–4 даёт +1 ко всем броскам, 5–7 даёт +2. Стартовые характеристики могут достигать 4; ХП без снаряжения рассчитываются как max(3, 3 + 2 × выносливость). Бег даёт 15 единиц прогресса в час. Медитация доступна раз за два дня, число уровней определяет мастер. Эти решения заменяют прежние несовместимые формулировки.

Материалы внешнего справочника рас не импортированы автоматически: сохранены авторский список и ссылка на источник стартовых наборов.


## Сюжет и журнал

Сценарий находится в `content/story.html`. В начале страницы — краткое положение персонажей, дальше — NPC, содержание сцен, квест, обучение, общий сюжет и журнал. Подготовленные события не считаются сыгранными. После сообщения мастера обновляются сводка и журнал; изменения инвентаря и характеристик вносятся только по фактическим событиям.

## Магия в редакции 0.10

Эйра заменяет отдельные источники общей энергией (начальные 4 единицы на персонажа). Ветви: Аугмент, Эмис, Шифт, Фордж, Нексус, Сингуляр. Общее владение, владения ветвями и личные искусства различаются. Склонности влияют на практику навыков, а не на характеристики или множители урона. Старые термины сохранены только в свёрнутом словаре перехода для мастера. Тайные способности на публичных карточках не раскрываются.
